# LID Downloader 🎵

## Quick Start

1. **Double-click** `LID_Downloader.exe` to start
2. Choose "Download a single song" or "Download a playlist"
3. Paste a YouTube URL
4. Click download and wait!

Your music will be saved to your **Music** folder by default.

---

## First Time Setup (Optional)

### For Better Audio Quality

This app can enhance audio to 320kbps quality using FFmpeg.

**Already included!** If you see an `ffmpeg` folder with `ffmpeg.exe` inside, you're all set.

**If missing:**
1. Download FFmpeg from: https://ffmpeg.org/download.html
2. Extract `ffmpeg.exe` from the download
3. Place it in the `ffmpeg` folder next to this app

---

## How to Use

### Single Song
1. Click "Download a single song 🎵"
2. Paste YouTube video URL
3. Click "Check URL" to verify
4. Click "Start Download"
5. Done! Check your Music folder

### Playlist
1. Click "Download a playlist 📜"
2. Paste YouTube playlist URL
3. Click "List Playlist Items" to preview
4. Click "Start Download"
5. Wait (10-40 seconds between songs to avoid blocks)
6. Done! All songs in your Music folder

### Change Save Location
- Look for "Output:" at the bottom
- Click "Change" to pick a different folder
- Your choice is remembered for next time

## Troubleshooting

**App won't start?**
- Extract the ZIP file first (don't run from inside ZIP)
- Right-click → "Run as Administrator"
- Allow in Windows Defender if blocked

**Download failed?**
- Check internet connection
- Try a different video
- Wait a few minutes if rate-limited

**Can't find downloaded songs?**
- Check your Music folder: `C:\Users\YourName\Music`
- Or check the folder shown in "Output:"

**Playlist taking forever?**
- Normal! App waits 10-40 seconds between songs
- This prevents YouTube from blocking you
